🔍 Scientific Methodology & Disjoint Split Audit

• Verified End-to-End Metric: Measures True Answer Correctness via deterministic execution verifiers (Python AST sandbox unit tests, numeric tolerance regex, and normalized QA aliases) across 300 test queries (75 GSM8K, 75 MBPP, 75 ARC, 75 TriviaQA). Completely eliminates the prior circular route-label matching metric.

• Disjoint Splits & Zero Contamination: Seeds (160 items) strictly from Train splits; Dev (100 items) and Test (300 items) strictly from held-out Val/Test. Zero exact string overlap (0/300) and max cosine similarity to seeds is 0.7826 (< 0.90 threshold).

• Hyperparameters Frozen on Dev: Tuning was performed exclusively on the 100-item Dev split ($k=7, \text{exponent}=1.0, \text{margin}=0.15, \text{near\_dup}=0.90$) and permanently frozen to config/frozen.json prior to the single held-out test evaluation.

• Paired Bootstrap Differences (10,000 resamples): Darwin Router vs Always-Small is +9.00 pp [95% CI: +5.67pp to +12.67pp]; vs Always-Big is -8.67 pp [95% CI: -12.33pp to -5.00pp]; vs Naive kNN is +2.33 pp [95% CI: +0.67pp to +4.33pp]; Darwin+Probes vs Darwin is +0.33 pp [95% CI: +0.00pp to +1.00pp].
